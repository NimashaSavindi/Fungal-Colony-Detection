# Fungal Colony Detection 

## 📖 Overview

This project applies computer vision and image processing techniques to detect fungal colonies and monitor their growth over time. By processing a sequence of fungal colony images, the system isolates colony regions from the background and generates binary masks for growth analysis.

---

## 🎯 Key Features

- Detect fungal colonies from digital images
- Segment colony regions from the background
- Generate binary masks for visualization
- Analyze colony growth progression over time
- Support automated biological image analysis

---

## 🔬 Methodology

### Image Processing Pipeline

1. **Image Acquisition** – Collect fungal colony images at different growth stages.
2. **Preprocessing** – Perform image enhancement and noise reduction.
3. **Segmentation** – Separate fungal colonies from the background.
4. **Binary Mask Generation** – Create binary images highlighting colony regions.
5. **Growth Analysis** – Track colony expansion and compare growth patterns.

---

## 📊 Results

The system successfully:

- Isolated fungal colony regions from petri dish images
- Generated binary segmented masks
- Visualized fungal growth progression across multiple stages
- Enabled automated monitoring of colony expansion
